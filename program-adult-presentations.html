About the program

This practical ICT program helps adult learners develop presentation skills for study, work, and everyday communication. Learners practise turning information into a clear visual story and delivering it with confidence.

Plan your message

Organise key points into a focused outline that is easy for an audience to follow.

Create clear slides

Work with slide layouts, text, images, and simple visual design choices.

Present with confidence

Practise presenting your work and using digital presentation tools effectively.

Learn by doing

Training centres on guided practice and a short presentation project, so learners can apply the skills as they build them.
